# Attributions and asset provenance

Every asset QSimCity ships is either generated from source in this
repository or is a dependency listed below with its licence. This document
is the audit trail: it states where each class of asset comes from, who
holds its rights, and why distributing it is permitted.

QSimCity itself is released under the **Apache License 2.0** (see
[`LICENSE`](../LICENSE)). Third-party runtime and build dependencies and
their licences are enumerated in
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

## Visual assets: none are third-party

There is no imported art in this project. Every pixel the user sees is
computed at runtime or generated by a script in this repository.

| Asset class | Where it comes from | Licence |
| --- | --- | --- |
| Building facades (windows, mullions, banding, lit-window patterns) | Generated as `DataTexture` pixel arrays at runtime by `packages/visual-engine/src/textures.ts`, from a hash-seeded deterministic function | Apache-2.0 (this repository) |
| Road, crosswalk, and water-ripple textures | Same module, same method | Apache-2.0 (this repository) |
| City geometry (terrain, roads, blocks, parcels, buildings, landmarks, props, interiors) | Computed from the plan in `packages/world/src/`, assembled into merged `BufferGeometry` by `packages/visual-engine/src/city-builder.ts` | Apache-2.0 (this repository) |
| Sky dome, sun disc, clouds, starfield | Procedural, `packages/visual-engine/src/sky.ts` | Apache-2.0 (this repository) |
| Vehicles, pedestrians, banners, container stacks | Primitive geometry built in `packages/visual-engine/src/vehicles.ts` and `engine.ts` | Apache-2.0 (this repository) |
| District and interior labels | Rendered to a `<canvas>` at runtime with the viewer's own system UI font | Apache-2.0 (this repository); glyphs come from the user's OS |
| Application icons (`apps/web/public/icons/icon-192.png`, `icon-512.png`) | Generated by `tools/make-icons.ts`, committed as build output | Apache-2.0 (this repository) |
| Favicon (`apps/web/public/favicon.svg`) | Hand-authored SVG primitives — a rounded square, a triangle outline, three dots | Apache-2.0 (this repository) |
| Onboarding illustrations | Inline SVG authored in `packages/ui/src/components/Onboarding.tsx` | Apache-2.0 (this repository) |
| Release screenshots in `release-evidence/` and Playwright baselines | Captured from this application by `tools/wiser/capture-screenshots.ts` and Playwright | Apache-2.0 (this repository) |

**No typefaces are bundled.** The interface names a stack of typefaces
that operating systems already ship —
`'Avenir Next', 'Segoe UI', system-ui, -apple-system, sans-serif` for body
text and `ui-monospace, monospace` for code — and renders in whichever of
them the viewer's system provides. Naming Avenir Next and Segoe UI asks
for fonts Apple and Microsoft license with their own operating systems; it
does not distribute them. Nothing is downloaded from a font CDN, and the
strict Content-Security-Policy forbids it.

**No audio files are bundled.** The ambient sound bed is synthesised in
the browser with the Web Audio API (`packages/visual-engine/src/audio.ts`);
there are no samples or recordings in the repository.

## Verifying the claim yourself

```bash
find apps packages -type f -not -path '*/dist/*' -not -path '*/node_modules/*' \
  \( -name '*.png' -o -name '*.jpg' -o -name '*.jpeg' \
  -o -name '*.gif' -o -name '*.webp' -o -name '*.svg' -o -name '*.woff' \
  -o -name '*.woff2' -o -name '*.ttf' -o -name '*.otf' -o -name '*.mp3' \
  -o -name '*.wav' -o -name '*.glb' -o -name '*.gltf' \)
```

On a source tree this returns exactly three files — the two generated
application icons and the hand-authored favicon above. Everything else
under `apps/` and `packages/` is source code. The `dist/` and
`node_modules/` exclusions matter: run it on a built tree without them and
the same three icons are counted twice, once in `apps/web/public` and once
in the build output copied from it.

**The demo video's captions** (`release-evidence/demo/qsimcity-demo.mp4`)
are drawn by the browser into the recorded page using the same
system-provided stack, so the recording shows whichever font the recording
machine had. No typeface is embedded in the video beyond the rasterised
pixels of the text itself.

Runtime dependencies are few and all permissively licensed; the full list
with versions and licence texts is in

| --- | --- | --- |
| three.js | WebGL renderer | MIT |

| Zustand | State container | MIT |

| Playwright | End-to-end testing (not shipped) | Apache-2.0 |
| Vitest | Unit testing (not shipped) | MIT |
| Qiskit, Qiskit Aer | Optional Python cross-validation bridge (not shipped to the browser) | Apache-2.0 |

`pnpm audit` runs in the release gate and must report no high or critical
advisories; two build-time transitive advisories are pinned to patched
releases through `pnpm-workspace.yaml` overrides, documented inline there.

## Names and trademarks

QSimCity is an independent educational project. It is not produced,
endorsed, sponsored, or approved by Electronic Arts, Maxis, IBM, or any
quantum-hardware vendor. No logotype, character, map, interface element,
or asset from any commercial product is reproduced or imitated. A
prohibited-name scanner (`tools/check-prohibited-names.ts`) runs in the
release gate to keep it that way.

Device topologies referenced by name in the app (for example a linear
five-qubit chain) are generic connectivity graphs defined in
`packages/domain/src/`, not vendor calibration data. Where the app shows
anything that would be vendor-specific, it carries a `CALIBRATION` or
`ESTIMATED` certainty label and names its source.
